# brand/ — rules for this folder

These rules apply to everything inside `brand/`, on top of the studio-wide rules
in the root `CLAUDE.md`.

**`voice.md` is the source of truth.** All copy for Kettlebird Tea follows it.
The root `CLAUDE.md` imports it so it is available in every session.

**Do not duplicate the voice rules.** If another file needs them, link to
`brand/voice.md` instead of copying the text.
